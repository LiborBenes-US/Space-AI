🕹️ Active Interface Features & Micro-Agent Registry

This interactive engineering specification demonstrates how individual Stealth AI Chopper Micro-Agents anchor directly to different user interface element frameworks inside the central Currency Converter demo workspace. 

1. 📝 The Title Text Element (`AI TYPOGRAPHY AGENT`)

• Trigger Behavior: Moving the cursor over the main application heading instantly forces the typography agent to hover over the layer.

• Local Control Overlays: Spawns interactive toggles for **Bold**, **Italic**, and explicit structural text alignments (**Left**, **Center**, **Right**).

• Dynamic Response: Clicking a font style or alignment toggle dynamically modifies the real-time CSS font properties of the title header directly on the canvas without textual code commands.


2. 🔢 The Amount Input Container (`AI INPUT AGENT`)

• Trigger Behavior: Hovering over the numerical text input frame summons the input configuration engine.

• Local Control Overlays: Features a visual horizontal width layout slider (Compact, Standard, Wide) alongside structural border styling selectors (Solid, Borderless, Underline).

• Dynamic Response: Adjusting the width slider instantly recalculates and updates the object's inline width dimensions across the active canvas frame.


3. 🔀 The Currency Selector Dropdown (`AI COMPONENT AGENT`)

• Trigger Behavior: Pointing to the USD/EUR exchange layer wakes up the structural component agent.

• Local Control Overlays: Exposes architectural configuration toggles including Menu Layout (Vertical Dropdown vs. Horizontal Pill Toggles) and **Display Style** (Currency Code Only vs. Integrated Country Flag Icons).

• Dynamic Response: Toggling the selections immediately changes the rendering framework of the choices on the screen.


4. ⚡ The Primary Execution Button (`AI CHOPPER AGENT`)

• Trigger Behavior: Hovering over the emerald green "Convert Currency" button summons the flagship layout optimization agent.

• Local Control Overlays: Provides a granular **Corner Radius slider (0px to 24px)** and a 4-color swatch design palette (Neon Green, Cyber Cyan, Dark Emerald, Indigo Blue).

• Dynamic Response: Moving the radius handle or selecting a color grid block instantly transforms the button's inline border-radius and background-fill CSS properties.


🔄 Real-Time Properties & State Lifecycle Synchronization

```
[ Human Interaction on Artboard ]
               ▼
[ Stealth Micro-Agent Local Slider Adjusted ]
               ▼
[ Real-Time CSS Updates Object Layout on Screen ]
AND
[ Right Sidebar Properties Data Panel Re-renders Instantly ]
```

When any component on the artboard is hovered or selected, the entire Right Sidebar instantly flushes its old data and re-renders to display the exact live measurements of that specific object. Sliding the corner radius handle on the button bubble, for instance, drives a mirroring slider and updates the exact numerical pixel values and hexadecimal color codes in the sidebar in real time. 

Moving the mouse away triggers the Stealth Mechanic, immediately clearing the bubble and restoring a clean artboard workspace for the creator.
