🕹️ What It Is

Space AI is a **design agent you hover over**. Point at a button in the central artboard,
and a floating control panel appears above it with clickable chips for every property:
color, shape, size, shade, theme, effects, text, hover behavior, and icon.

Every action — a chip click or a typed natural-language command — produces a **style token object** that is immediately rendered to the button and mirrored in the right-hand
properties panel. Move the mouse away and the panel vanishes, restoring a clean canvas.

The entire parser is local. That means:

🚫 **No network requests** — nothing leaves the page.
⚡ **Instant response** — commands parse in under a millisecond.
🎯 **Deterministic** — the same prompt always produces the same result.
🔌 **Zero setup** — no API key, no server, no build step.

This is the reliable baseline that Phase 3 will extend with LLM-driven parsing.


🎨 The Artboard Button

The demo element is a "Submit Data" button in the center of the canvas. It was chosen
because buttons expose the widest useful surface of CSS properties in a small footprint —
background, geometry, typography, effects, motion, and hover state — all visible at once.

Every property below can be set by **clicking a chip** or **typing a prompt**. Both paths
feed the same parser pipeline.

🎨 Color

15 swatches covering the full spectrum, plus named synonyms (`neon pink`, `light blue`,
`dark green`, `hot pink`, `charcoal`) and raw hex input (`#ff8800`). Modifiers `darker`
and `lighter` shift the current color by ±25%.

🔷 Shape

`square` · `rounded` · `pill` · `circle`. Circle switches the button to a fixed square dimension with `border-radius: 50%` and hides the label.

📏 Size

`sm` · `md` · `lg` · `xl`, plus `taller` and `shorter` for height-only adjustments
without changing width.

🌗 Shade (directional light/dark ramp)

A gradient **derived from the current color** — dark on one side, light on the other.
Five directions: `→ ← ↓ ↑ ⤡`. Change the base color and the ramp re-tints automatically.
This is what "gradient" means here: a brightness variation of one hue, not a multi-color
palette.

🎭 Theme (named palettes)

Fixed multi-color gradients for when you want a specific look, not a tint of the current
color. Ten presets: `sunset` · `ocean` · `forest` · `purple` · `fire` · `ice` ·
`midnight` · `neon` · `candy` · `cyber`.

✨ Effects

• **`glow`** — outer halo in the current color (two-layer, soft falloff)

• **`shadow`** — drop shadow + inner top highlight for depth

• **`stripes`** — repeating diagonal white lines overlay

• **`glass`** — translucent background + backdrop blur + subtle white border

• **`outline`** — 2px white border

• **`3D`** — solid offset edge below the button; presses down on `:active`

• **`alive`** — continuous hue cycling (~8s) plus gentle opacity breathing (~4s)

• All effects **compose**. A "neon alive glass 3D" button is a valid, stable state.

✍️ Text

`bold` · `bolder` · `italic` · `uppercase` · `spaced` (letter-spacing) · `mono`
(monospace font family).

🖱️ Hover

Choose what happens when the cursor enters the button: `raise` (lift 4px) · `grow`
(scale 1.06) · `glow` (colored halo). These use the `:hover` pseudo-class, so they
don't conflict with any other effect.

🎯 Icon

15 emoji to swap the leading glyph:

📊 🚀 ✓ ⚡ ★ ♥ ⚙ 🔔 🔥 💎 ✨ 🎯 ➕ ▶ ☰

🔤 Label

The button's visible text. Change it via the prompt: `rename to Launch`.


🗣️ The Prompt Input

Below the chip rows sits a monospace input field. Type a natural-language command and
press Enter. The panel briefly shows a "thinking" state (for parity with the future LLM
mode), then applies the result.

The parser understands the full vocabulary of the chip rows, plus combinations and
qualifiers:

```
pill neon alive glass bold uppercase
shade up purple glow
3D large red shadow hover raise
circle icon lightning alive
sunset theme glass outline
rename to Launch
darker
no glow
```

Multi-command prompts compose cleanly. Every parser output is a **sparse patch** applied
on top of current state — nothing is reset between commands unless you ask for it.


📋 Copy CSS

The ⧉ **CSS** button next to the prompt copies a **production-ready stylesheet** for the
current button to your clipboard. It includes:

• All inline properties (background, radius, padding, font, color, border, shadow)

• The `::before` pseudo-element rule if stripes are active

• The `:active` rule if 3D is active

• The `@keyframes` block if `alive` is active

• The `:hover` rule if a hover effect is selected

Paste it straight into a real project and the button looks identical. This is the feature
that turns the prototype from a toy into a **design export tool**.


🔄 Real-Time State Lifecycle

```
   [ Cursor enters button ]
              ▼
   [ Stealth panel appears above the element ]
              ▼
   [ User clicks a chip — or types a prompt ]
              ▼
   [ parseIntent() produces a style patch ]  ◄── local keyword engine
              ▼
   [ applyPatch() merges into state ]
              ▼
   [ render() writes to the button's inline CSS ]
   AND
   [ Right sidebar re-renders with live measurements ]
              ▼
   [ Cursor leaves — panel fades out, canvas is clean ]
```

The right sidebar mirrors every property in real time: label, border-radius, fill hex,
size, shape, active effects, active text styles, and hover mode.


🧱 Architecture

One state object. One parser. One renderer. One DOM writer.

```js
state = {
  color, radius, size, shape,
  effects:  { glow, shadow, stripes, glass, outline, '3D', alive, shade, theme },
  shadeDir: 'right' | 'left' | 'down' | 'up' | 'diagonal',
  theme:    'sunset' | 'ocean' | 'neon' | ...,
  text:     { bold, bolder, italic, uppercase, spaced, mono },
  hover:    'raise' | 'grow' | 'glow' | null,
  icon, label
}
```

Every UI action produces a **patch** to this object. `applyPatch()` merges the patch,
`render()` walks the object once and writes inline CSS. There is no intermediate
representation, no virtual DOM, no framework.

🔌 The LLM swap point

The parser is intentionally isolated. When Phase 3 ships, **one line changes**:

```js
// Phase 2 (this version):
const patch = parseIntent(text);

// Phase 3 (API-backed):
const patch = await callLLM(text);
```

Everything downstream — `applyPatch`, `render`, the chip rows, the sidebar readouts,
Copy CSS — keeps working unchanged, **provided the LLM returns the same token shape**. This is why the local prototype matters: it locks in the contract.

🎯 Target Audience

• **Designers** who want to explore button styling without writing CSS by hand.

• **Developers** who need a ready-to-paste CSS snippet and don't want to look up
  properties one at a time.

• **Product teams** demonstrating what "AI-driven design tools" might feel like before
  any API is involved.

• **Anyone curious** about the natural-language → design-token pipeline, in a form
  they can read end to end in a single file.


🔒 Security & Privacy

• **No data collection** — No analytics, no tracking, no third-party requests.

• **No `eval()`, no `innerHTML`** — All chip rows and log entries are built with
  `document.createElement` and `textContent`.

• **No storage** — Nothing is written to `localStorage`, cookies, or IndexedDB.

• **No network access** — The page makes zero requests after loading.

• **Clipboard write only** — the Copy CSS button writes to the clipboard when clicked.
  The clipboard is never read.

🚀 Running It

Locally

1. Save the file as `index.html`.

2. Double-click it — the browser opens it directly.

3. Hover the green button. The agent panel appears above it.


On GitHub Pages

1. Push `index.html` to your repository.

2. Repo → **Settings** → **Pages** → Source: `main` branch, `/root`.

3. Wait 1–2 minutes.

4. Live at `https://<username>.github.io/<repo>/`.


⚠️ Limitations

📚 **Local parser only.** Understands the vocabulary defined in this document. New
  words require adding entries to the dictionary — there is no learning or fuzziness.

🎨 **One element.** The canvas currently holds a single button. Multi-element
  selection is planned for a later phase.

🎬 **No undo.** Each action is final; **↺ Reset all** returns to defaults.

🖥️ **Desktop-first.** Works on tablet, untested on phones.

🎭 **Ten themes, seven effects.** A curated useful set, not exhaustive.
